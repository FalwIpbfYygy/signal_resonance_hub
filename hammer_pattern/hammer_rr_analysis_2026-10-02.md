## 一、单一形态交易计划模板（所有已发现形态均为看涨锤子，共用一套）

| 项目 | 定义 |
|---|---|
| 触发条件 | 锤子收盘后，下一根（或当根突破）收盘价 **> 锤子最高价 H** → 多头触发 |
| 入场 | `H + 0.5 tick` |
| 止损 SL | `L − buffer`，`buffer = max(0.5, 0.3×ATR)` |
| 风险 R | `入场 − SL` |
| TP1 | `入场 + 1.0×R` |
| TP2 | `入场 + 2.0×R` |
| 盈亏比 | TP1 = **1:1**；TP2 = **2:1**（结构固定值，非基于阻力位，见缺失项⑤） |
| 置信度 | 量比↑ + 落在 40 根局部低位 + 前 20 根下行 → 高；否则中/低（无更高周期 S/R 确认，见缺失项①） |
| 失效条件 | 入场前价格跌破 **L（锤子最低）** → 形态失效，放弃；或触发后回破 SL 平仓 |

> 做空：已发现集合 **全部为看涨锤子**，不含任何看跌形态（射击之星 / 看跌倒锤 / 顶部结构）。因此从这 529 个形态**无法推导做空计划**——做空需另寻顶部反转形态（不在本次已发现集合内）。**做空盈亏比：不适用 / 信息不足。**
